# MASCLI RC 2.7 — Gestión preventiva y respuesta territorial

Nueva tabla de planes de acción por proyecto vinculados a alertas RC 2.6 corroboradas o en seguimiento. Se registra responsable, plazo, actividad, estado, avance (0-100%), notas y URL de evidencia; incluye historial de cambios y resumen de vencimientos/cumplimiento.

**Instalación:** usar los comandos y scripts de inicio existentes. Base de datos SQLite actualizada automáticamente al utilizar los endpoints nuevos. Respaldar `data/mascli.db` antes de migrar desde otra versión. No sustituir una base de datos con registros propios por la de muestra.

**Restricciones:** no hay sistema de autenticación/autorización empresarial; usar solo en entorno local/controlado, sin información personal sensible. La puntuación de alertas y el seguimiento no modifican IRSA, ni demuestran reducción de riesgo.

**Pruebas:** ver PRUEBAS_RC_2_7.txt.
