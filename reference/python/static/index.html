REGLAS DE SEGURIDAD

Principios del sistema

  • La IA/regla automática sugiere; el analista decide.
  • Una narrativa negativa por sí sola no activa rojo.
  • Información no verificada se trata con menor fuerza probatoria.
  • Las alertas naranjas y rojas requieren revisión humana.
  • Pesos y umbrales del IRSA no se presentan como validados hasta la etapa experta.
  • Cada resultado debe conservar fuente y trazabilidad.
CONFIGURACIÓN DEL PROTOTIPO

Administración del sistema

Gestión demostrativa de usuarios y roles. No implementa inicio de sesión ni control real de acceso.

Prototipo sin autenticaciónLos roles documentan el perfil previsto, pero esta versión no aplica permisos ni protege datos sensibles.
