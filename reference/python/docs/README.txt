ESTADO
Esta versión SÍ puede construirse antes de recibir el juicio de expertos, pero
NO debe denominarse todavía “V0.5 validada”. Su nombre correcto es:
SIPGES V0.5.1 CALIBRACIÓN TÉCNICA / CANDIDATA A VALIDACIÓN.

NOMENCLATURA CANÓNICA
La comunidad se registra como:
COMUNIDAD CAMPESINA SAN MARTÍN DE SECHURA (CCSMS).

La denominación canónica se utiliza en las fichas analíticas y salidas del
sistema. Los textos de las fuentes originales se conservan sin modificar para
mantener trazabilidad documental.

QUÉ CONTIENE V0.5 PREVALIDACIÓN
- Base Maestra importada.
- Dashboard y módulos operativos.
- Indicadores G1–I6.
- Motor IRSA.
- Explicabilidad.
- Persistencia SQLite.
- Auditoría.
- Panel de validación experta.
- Nomenclatura institucional normalizada.
- Preparación para incorporar V de Aiken y decisiones post-expertos.

CUÁNDO PASA A “V0.5 VALIDADA”
1. Recibir instrumentos reales de expertos.
2. Calcular V de Aiken.
3. Revisar observaciones.
4. Registrar decisión por indicador.
5. Implementar los ajustes aceptados.
6. Congelar la versión y generar el reporte de validación.

Por tanto: sí podemos tener V0.5 ahora, pero como versión PREVALIDACIÓN.

V0.5.1 mejora el clasificador con reglas ponderadas/contextuales. Sigue pendiente la validación independiente.
