# SIPGES RC 1.7 — Inteligencia estratégica territorial

Actualización incremental de RC 1.6. No elimina funcionalidades anteriores.

## Módulos agregados
- Actores e intereses (posiciones, intereses, preocupaciones, BATNA)
- Diseño y seguimiento de procesos de diálogo y consenso
- Cartera de oportunidades de valor compartido
- Joint Fact Finding / hechos compartidos
- AARC: reconocimiento, agencia, reciprocidad y claridad
- Dashboard estratégico con indicadores de completitud y seguimiento (conteos descriptivos)
- Informe ejecutivo estratégico Word editable

## Ejecución
Windows: descomprimir y ejecutar `INICIAR_SIPGES_FINAL.bat` (o `start_sipges.bat`). Si faltan paquetes instalar `pip install -r requirements.txt`. Se recomienda Python 3.11+.
Iniciar la app y entrar a «Inteligencia estratégica» en el menú.

## Precauciones
La herramienta usa SQLite local y no implementa autenticación real. No alojar en internet con datos personales o sensibles sin control de acceso, seguridad y evaluación legal. No carga datos inventados en módulos nuevos. El informe y la evaluación AARC requieren revisión humana. El índice IRSA permanece sin modificación.
