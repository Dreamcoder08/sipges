# Rename the administrator login mascli-admin → sipges-admin

The production administrator signs in as `mascli-admin`, a leftover of the MASCLI → SIPGES rename.
Rename the account everywhere the username is stored, so it is one person under one name.

## Specs

- S1 — «yes cambia a sipges-admin» (reply to: «Decidir si cambiamos tu usuario de login de `mascli-admin` a `sipges-admin`»).
- S2 — After the change, the account signs in with `sipges-admin` (password and Google), keeps its role, grants, Google link, push subscriptions and open sessions, and no stored reference to `mascli-admin` remains in any column that holds a username or an actor/attribution name (grants, sessions, push subscriptions, audit actor, created_by/updated_by, decided_by, reviewer, author, and any other).
- S3 — Attribution history is renamed too, so the four-eyes rule (docs/adr, migration 0028) still sees one person: a proposal by `mascli-admin` cannot be approved by `sipges-admin`.
- S4 — Fail closed: if `sipges-admin` already exists, the migration stops and rolls back; if `mascli-admin` does not exist, it does nothing.
