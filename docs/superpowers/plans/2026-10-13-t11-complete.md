# T11c/d complete frontend implementation plan

> **For agentic workers:** Follow test-driven-development. Implement independent feature slices in parallel with disjoint files; root integrates and performs verification and independent review. User explicitly authorized autonomous completion of all T11.

**Goal:** Complete every remaining menu route with operational TypeScript UI, and close the event-classification parity gap from T11b.
**Architecture:** Feature-isolated React modules consume Zod contracts and existing Hono use cases. The app supplies FeatureContext and composes modules. Typed read-only reference-data adapters fill the missing geographic endpoints; no default-project geometry is exposed as another tenant's geometry.
**Tech Stack:** Existing React/Vite, TanStack, Zod, Hono, pnpm/Vitest/MSW; no new runtime dependencies.
**Spec:** docs/migration/web.md, ODD T11, ADRs 0002/0006/0007/0008 and behavior contract.

## Global constraints

- No changes to Python runtime; no real-data migrations or deployments.
- Scoped keys and X-MASCLI-Scope for all protected calls, including binary downloads and multi-step writes.
- Root route keys reset features on project changes; cancel/read pending work using query signals.
- Server remains authoritative for roles, state transitions and corroboration.
- Shared UI and contracts only across features; app composes strategic record editors through a callback.
- Accessible Spanish UI, escaped content, safe HTTP(S) links, descriptive errors, duplicate-operation guards and explicit destructive confirmations.
- Scientific validation and lexical/semantic findings remain provisional. Do not invent model readiness, precision, coordinates or measured impact.

## Review focus

1. Project switching during file analysis, review import, IRSA configuration and administrative writes.
2. Partial failures and duplicate submissions, stale results and mutation completion erasing later drafts.
3. Role restrictions, final-admin protections and MFA setup/enable semantics.
4. Candidate findings versus corroboration, unavailable embeddings and missing geographic data.
5. Binary exports, CSV formula handling, source links and import values treated as text.
